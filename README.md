# Local Messenger

Local Messenger is a peer-to-peer Flutter messaging application for devices on the same LAN. Currently in progress. 

## Current status

Opening the app in different devices under the same network shows the device in the nearby devices section

See [the architecture](docs/architecture.md), [protocol outline](docs/protocol.md), and [implementation tracker](tasks/todo.md).

## Supported targets

- Android
- Windows
- macOS
- Linux
